# WB FBS System

Система автоматизации работы с заказами Wildberries по модели FBS.

## Структура

- `database/schema.sql` — актуальная структура PostgreSQL без данных.
- `database/functions/` — SQL-функции.
- `database/views/` — SQL-представления.
- `database/migrations/` — изменения структуры базы данных.
- `database/docs/` — документация и карта базы данных.
